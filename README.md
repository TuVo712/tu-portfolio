# Tu's Portfolio — Version 1

A static, responsive personal portfolio made with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser. No installation or build tools needed.

## Customize before publishing

1. In `index.html`, replace `YOUR_EMAIL@example.com` with your real email.
2. Replace `https://github.com/` and `https://www.linkedin.com/` with your profile URLs.
3. Review your name, introduction, project descriptions, and spelling preferences.
4. Add real screenshots and links only after confirming permission to share team or course materials.
5. Optionally add a PDF CV and a link to it.

The project artwork is original CSS illustration, **not** actual screenshots. The portfolio does not yet include detailed project case studies.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main**, folder **/(root)**, and save.
6. GitHub Pages will display your live site URL when deployment finishes, typically `https://YOUR_USERNAME.github.io/portfolio/`.

Alternatively, use a repository named `YOUR_USERNAME.github.io` to publish at `https://YOUR_USERNAME.github.io/`.
